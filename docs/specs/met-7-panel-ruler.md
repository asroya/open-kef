# Feature spec: menu-bar panel, direction C "The ruler"

Filled from `docs/spec-template.md`. Tokens are from `design/tokens.json` v0.2.0.

---

**Linear ticket:** MET-7
**Goal (one sentence):** A 320pt menu-bar panel that controls a KEF LSX II LT: volume on a tick ruler, source switching, play/pause and now playing, without opening the main window.
**User story:** As Abhi, I want to set my speaker's level, source and playback from the Mac menu bar so that I never have to open KEF Connect or the main window for everyday control.

## Acceptance criteria
- [ ] Clicking the menu-bar item opens a panel exactly `size.panelWidth` wide, using `material.panel`.
- [ ] **Now-playing row**
  - [ ] Shows art (`size.art`, `radius.art`), title (`type.title`), artist (`type.body`, `color.*.textMuted`) and one play/pause button (`size.iconHit`).
  - [ ] Title and artist truncate with an ellipsis on one line.
- [ ] **Volume ruler**
  - [ ] Draws a minor tick every `space.1` and a major tick every 10 minor ticks.
  - [ ] Ticks below the current level use `color.*.text`; the rest use `color.*.line` (minor) and `color.*.textMuted` (major).
  - [ ] A 1pt cursor line marks the level, with the value above it in `type.numeric` (tabular figures).
- [ ] **Volume input**
  - [ ] Dragging or clicking the ruler sets volume through `Speaker::set_volume`.
  - [ ] Arrow keys step the volume while the ruler is focused (step size pending MET-6, Q5).
  - [ ] VoiceOver reads it as a slider named "Volume" with its value.
- [ ] **Sources**
  - [ ] Shown as a single row of text buttons (`type.body`), separated by `space.3`.
  - [ ] The active source is `color.*.text` at `type.title` weight; inactive sources are `color.*.textMuted`.
  - [ ] Selecting a source calls `Speaker::set_source`, and the row exposes the active source to assistive tech (radio-group semantics).
- [ ] The footer shows `<deviceName> · <modelName>` in `type.label`, `color.*.textMuted`.
- [ ] Focus uses the system focus ring (`focus.*` applies to the HTML mockups only).
- [ ] Disabled controls use `opacity.disabled`.
- [ ] Light and dark modes follow the system and use `color.light` / `color.dark` exactly.
- [ ] Red (`color.*.danger`) appears only in the offline state.
- [ ] State changes animate with `motion.fast` / `motion.base` and `motion.easing`, and don't animate when Reduce Motion is on.

## Speaker API calls
| Action | `crates/core` function | Endpoint / setting path |
|---|---|---|
| Read volume | `Speaker::volume` | `GET /api/getData`, `player:volume` |
| Set volume | `Speaker::set_volume(u8)` | `POST /api/setData`, `player:volume` |
| Read source | `Speaker::source` | `GET /api/getData`, `settings:/kef/play/physicalSource` |
| Set source | `Speaker::set_source(Source)` | `POST /api/setData`, `settings:/kef/play/physicalSource` |
| Play / pause | `Speaker::control("pause")`, and "play" (**unverified**: the docs only show pause, next and previous) | `player:player/control` (`roles=activate`) |
| Now playing | `Speaker::get(path::PLAYER_DATA)` (no typed helper yet) | `player:player/data` |
| Device footer | `Speaker::get` | `settings:/deviceName`, `settings:/kef/host/modelName` |
| Offline / standby | `Speaker::get(path::SPEAKER_STATUS)` + request timeout (**pending MET-6**) | `settings:/kef/host/speakerStatus` |
| Live updates | no helper yet | `/api/event/modifyQueue`, `/api/event/pollQueue` |

## Edge cases
- **Long titles and artists:** one line, ellipsis. Long device names truncate in the footer.
- **No artwork or no now-playing data:** the art slot shows a note icon at `color.*.textMuted`. For non-streaming sources, see MET-6 Q4.
- **Volume at 0 or at maximum:** the cursor sits at the ruler's edge and the readout must stay inside the panel. The scale is 0–100 until MET-6 Q5 answers it.
- **Volume changed elsewhere** (KEF Connect, the remote) while the panel is open: the ruler follows within one `pollQueue` cycle, with no animation on Reduce Motion.
- **Drag while a set is still in flight:** send only the latest value and don't echo stale values back.
- **Source not supported by the LSX II LT:** don't render it (MET-6 Q1).
- **Standby vs unreachable:** they must look different (MET-6 Q2). The mockup only covers unreachable.
- **Multiple speakers:** out of scope. The panel binds to one discovered speaker.
- **Firmware adds auth or HTTPS** (`kef-protocol.md`, still-needed item 5): treat it as the Error state.

- **Detector problems: 0** (`npx impeccable detect`, v4.5.2, `c-the-ruler.html`).
  - The 5 `tiny-text` findings on the 11pt `type.label` are waived inline, citing the v0.2 token rule "11pt label is allowed: macOS menu-bar scale".
  - One advisory remains: `repeating-stripes-gradient` on the ruler ticks. It's advisory only, and the ticks carry data.
- **Checklist score: 3/17** (pass ≤ 4). One point each for:
  - Line 3: monochrome with hairlines.
  - Line 7: ticks that read close to a grid texture.
  - Line 15: menu-bar text sizes.
  - No 2s.
- **One clear idea:** yes. Hi-fi gear is about precise level, so volume is a measuring ruler on the 4pt grid.
- **One signature element:** yes, the tick ruler with the tabular level riding the cursor.
- **One accessory cut:** yes. The footer source label that repeated the source row was removed.

## Provisional, pending MET-6
- **Provisional states:** Speaker offline and Changing source. Both may change once MET-6 confirms what the API reports.
- **Open questions:**
  1. Which `kefPhysicalSource` values does the LSX II LT accept? The mockup assumes wifi, bluetooth, tv, optic and usb. The code also has coaxial and analog.
  2. How does offline show up (HTTP timeout, mDNS drop, or `speakerStatus = standby`)? Standby and unreachable need different UI.
  3. Is a source change instant, or is there a transitional state we can see through `pollQueue`, and how long does it take?
  4. Does `player:player/data` keep the old track after switching to TV or Optical, or clear it?
  5. Is volume 0–100, or capped by `maximumVolume` / `volumeLimit`, and what is `volumeStep`?
  6. Do play/pause, next and previous work on every source, and is "play" a valid `control` value?
- **Token requests:**
  - Closed by tokens v0.2: icon size and weight, focus ring, disabled treatment, spinner, panel material, and 11pt labels.
  - **Still open:**
    - A token for the ruler tick width and tick-colour roles. The mockup uses 1pt and existing colour keys.
    - The dotted "pending source" underline style.
    - Whether the 1pt panel border in the mockup should be dropped in favour of `material.panel`.

## Out of scope
- Directions A and B; the main window; multiple speakers or zones.
- Mute, standby, EQ, next/previous in this panel (C shows play/pause only), streaming-service hand-off, onboarding.
