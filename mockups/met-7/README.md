# MET-7 · Menu-bar panel directions

Three static mockups of the open-kef menu-bar panel for KEF LSX II LT: volume, source, play/pause and a now-playing strip.
Each is 320pt wide (`size.panelWidth`) and uses only values from `design/tokens.json`. The CSS is generated by `gen.py`, which reads the tokens file directly.

| File | Direction |
|---|---|
| `a-the-number.html` | A · The number |
| `b-the-menu.html` | B · The menu |
| `c-the-ruler.html` | C · The ruler |
| `board.png` | All three, all states |
| `shots/<direction>--<state>.png` | One 2x crop per state (`playing`, `paused`, `offline`, `switching`) plus `--all` |

**Provisional:** the *Speaker offline* and *Changing source* states are guesses until MET-6 confirms what the speaker API reports.
Track names, the volume value (40, from the protocol doc's example payload) and "Living Room" are placeholder copy.

## Directions

**A · The number**
- **Thesis:** you open this panel to change loudness, so the volume figure is the interface.
- **Signature:** the 22pt tabular volume readout (`type.numeric`) leads the panel, locked to the slider.
- Sources are a five-way segmented control and now playing is a strip at the bottom.

**B · The menu**
- **Thesis:** a menu-bar extra should behave like a Mac menu, not a mini app.
- **Signature:** the sources are real menu rows (`size.rowHeight`) with a checkmark and ⌘1–⌘5, so the whole panel works from the keyboard.
- Standby and "Open open-kef…" sit at the bottom, as in a native menu.

**C · The ruler**
- **Thesis:** hi-fi gear is about precise level, so volume is drawn as a measuring ruler on the 4pt grid.
- **Signature:** a tick ruler (one tick every `space.1`, majors every 10 ticks) with the tabular level riding the cursor.
- Sources are a quiet text row.

## Hostile critique → iteration 1
- **A:** the number sat at the right-hand end of the slider like any system slider value, so it wasn't a signature.
  - Moved it to lead the row.
  - Removed a duplicate "Switching to TV" note.
  - Replaced an invented IP address in the offline copy.
  - Unchecked the source and hid the slider thumb while offline, since a level of 0 would be a lie.
- **C:** the riding numeral collided with the artist line. Added `space.5` above the ruler and dropped a footer source label that repeated the source row.
- **B:** hid the slider thumb when offline. B remains the "safe" direction.

## Token requests (for design snob bro)
1. **Glyph size and stroke weight for SF Symbols.** The stand-in glyphs use 16pt (`space.4`) with a 1.5 stroke, which isn't in the tokens.
2. **Focus ring.** Width and offset are currently 1pt, the hairline value.
3. **Slider thumb size and border.** Currently `space.3` with `radius.control`, which makes a circle by accident.
4. **Disabled/offline treatment.** There's no opacity or disabled colour token, so `textMuted` is used.
5. **Indeterminate progress.** Changing source has no motion token for a spinner or period, so it's shown statically.
6. **Larger display numeral** if direction A is chosen. `type.numeric` at 22pt is the ceiling.
7. **Panel elevation or material.** A native menu-bar panel uses vibrancy and a shadow; the mockups use only a 1pt `line` border.
8. **Dark mode** is wired from `color.dark` but not screenshotted.

## Open questions for MET-6
1. Which `kefPhysicalSource` values does the LSX II LT actually accept? The mockups assume Wi-Fi, Bluetooth, TV, Optical and USB. `coaxial` and `analog` appear in the code but are probably not on the LT.
2. How does "offline" show up? Is it an HTTP timeout, an mDNS drop, or `speakerStatus = standby`? Standby and unreachable need different UI.
3. Is a source change instant, or is there a transitional state we can observe through `pollQueue`? How long does it take?
4. Does `player:player/data` keep reporting the old track after switching to TV or Optical, or does it clear?
5. Is the volume range 0–100, or capped by `maximumVolume`/`volumeLimit`? And what is `volumeStep`?
6. Do prev/next work for every source (TV, Optical), or only for streaming sources?

Fonts: the mockups use the SF system stack. The screenshots were rendered on Linux, where it falls back to a substitute, so check the type on a Mac.
